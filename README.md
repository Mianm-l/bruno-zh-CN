## 📌 适配版本

* **推荐适配版本**：**Bruno v4.3.0**（官方 Windows 64位 便携版 Portable / 安装版 Setup）
* **小版本兼容性**：支持后续 **v4.3.x** 小版本直接平滑升级使用。

---

## ⚡ 极简安装方式（3 秒搞定）

> [!TIP]
> 补丁自带路径自动探测与原生英文自动备份机制，全自动一键完成，无需手动修改任何代码。

1. **退出 Bruno**：确保电脑上的 Bruno 客户端处于关闭状态；
2. **双击运行**：直接双击运行项目根目录下的 **`install.bat`**；
3. **完成启动**：脚本会自动备份并完成补丁注入，按提示启动 Bruno 即可直接使用纯中文界面！

> 🔄 **如需还原回官方英文原版**：随时双击运行根目录下的 **`uninstall.bat`**，即可一键完美还原。

## 💻 高级安装（自定义路径）

如果您的 Bruno 安装在非默认目录（默认支持 `D:\Program Files\Bruno`、`C:\Program Files\Bruno` 等常见目录），您可以通过以下方式安装：

* **方式 1**：直接运行 `install.bat`，当检测不到时会提示您手动输入 Bruno 安装根目录；
* **方式 2**：打开终端运行命令行传入路径：
  ```bash
  python patch.py "D:\你的安装路径\Bruno"
  ```

## ✨ 汉化特性与优势

1. **双层混合汉化引擎**：
   * **底层静态直出**：顶栏菜单、汉堡菜单、空状态快捷键等最高频组件直接静态汉化，**启动瞬间直显中文，绝无白屏或英文闪烁**；
   * **运行时动态拦截**：监听动态弹窗、右键菜单、Mantine 下拉框，全面捕获异步组件。
2. **CodeMirror 占位符智能穿透**：
   * 精准汉化参数名、参数值等表格占位提示，同时**严格隔离代码编辑区域**，100% 保障不影响用户的接口脚本、Headers、JSON 等任何实际业务请求数据。
3. **100% 离线安全**：
   * 不依赖任何第三方网络服务，纯本地执行，专为内网与涉密开发环境设计。
4. **安全无损回滚**：
   * 首次执行安装时会自动将原始核心备份为 `app.asar.bak`，还原零残留。

## 📂 项目工程目录

```text
bruno-zh-CN/
├── README.md                      # 纯中文权威使用说明文档
├── install.bat                    # Windows 用户一键自动安装批处理（双击即用）
├── uninstall.bat                  # 一键卸载与还原官方英文批处理
├── patch.py                       # 核心自动化补丁注入与打包引擎
├── restore.py                     # 核心还原脚本
├── package.json                   # 项目元数据与依赖定义
├── .gitignore                     # Git 忽略规则
├── core/
│   ├── i18n-zh.js                 # 运行时动态汉化引擎与拦截器
│   ├── menu-template.js           # Electron 系统顶栏与原生菜单模版
│   ├── dict.json                  # 全量中文翻译词典 (500+ 高频词条)
│   └── replacements.json          # React 核心代码静态直出替换表
└── tools/
    ├── extract_ui_strings.py      # 新版本 Bruno 词条自动提取工具
    └── pack_asar.js               # asar 资源二次封包工具
```

## 🛠️ 后续新版本词条维护

若 Bruno 官方后续发布了新的次版本（如 v4.4.x）：

1. 运行提取工具抓取新词条：
   ```bash
   python tools/extract_ui_strings.py
   ```
2. 在 `core/dict.json` 中补充新增词条的中文映射；
3. 重新运行 `install.bat`，即可一键生成适用于新版本的汉化包！
